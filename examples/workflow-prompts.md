# Example prompts

These examples demonstrate the plugin without assuming that memory is written automatically.

## Recall and resume

- Bring me up to speed on this project using XMemo. Show the latest verified state, active decisions, open TODOs, blocker, and exact next action.
- Recall what we decided about the release architecture and explain any conflicting or outdated memories.

## Distill and checkpoint

- Turn this conversation into durable XMemo memory. Preview the decisions, TODOs, unresolved questions, and working-state checkpoint before saving.
- Save a restart-ready checkpoint for this task, including completed evidence, work not to repeat, and one exact next action.

## Plan and progress review

- Review this implementation plan against our saved XMemo decisions. Return a verdict, critical findings, missing evidence, and an acceptance gate.
- Audit this agent's progress report against the latest saved plan and project state. Separate verified work from claims.

## Cross-agent handoff

- Prepare an XMemo handoff for Codex. Include the objective, verified status, decisions, artifacts, constraints, remaining work, blocker, and exact next action.

## Lifecycle

- Find the exact memory about our deprecated deployment process and soft-delete it.
- Restore the memory I just soft-deleted.
